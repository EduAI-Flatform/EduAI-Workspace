# ADM-01 Acceptance

- Stitch MCP evidence exists for every substantial shell redesign.
- Desktop, tablet and mobile compositions are deliberate and coherent.
- Navigation grouping, active state, identity and return-to-product behavior are defined.
- Existing global token foundation is reused/adapted rather than replaced arbitrarily.
- Semantic success/warning/danger/info colors remain meaningful.
- Approved patterns cover headers, panels/cards, dense data, filters, forms, status badges, dialogs/drawers and empty/loading/error states.
- Accessibility and long Vietnamese copy are considered before implementation.
- Phase evidence/CI/Git gates pass.
