# ADM-01 — Admin Design System & Shell

**Status:** PLANNED  
**Dependency:** ADM-00 DONE  
**Execution authorized:** NO

## Objective
Use Stitch to define and approve the common EduAI Admin visual language and shell before page-family implementation.

## Scope
Palette/token use, typography hierarchy, spacing/radius/elevation, page header, sidebar grouping, active states, identity area, desktop shell, tablet behavior, mobile top bar/drawer, card/table/form/modal/badge patterns and semantic status colors.

## Key UX direction
Replace the long mobile horizontal Admin destination strip with an intentional drawer/sheet navigation if ADM-00 confirms the current behavior is inadequate. Group navigation into coherent sections rather than one flat list.

## Out of scope
Broad page-family rewrites; payment logic; backend contract changes.

## Exit gate
Approved Stitch references exist for shell/design language including desktop and mobile compositions; implementation contract is clear enough for ADM-02.
