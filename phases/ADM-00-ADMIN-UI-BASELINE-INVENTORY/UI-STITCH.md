# ADM-00 Stitch Policy

ADM-00 does not redesign screens. It inventories any existing Stitch references and identifies which surfaces need new Stitch work.

For each surface record:
- existing Stitch reference/evidence if available;
- `STITCH_APPROVED`, `NEEDS_POLISH` or `RAW_UI`;
- desktop/mobile deficiencies;
- whether ADM-01, ADM-03, ADM-04 or ADM-05 must create/refine a Stitch design.

Do not prompt Stitch merely to generate alternative versions of already-approved UI.
