# ADM-00 Test Plan

This is primarily an audit phase.

1. Run relevant existing Admin navigation/component tests to establish baseline.
2. Open every Admin route with a TEST/admin session where available.
3. Capture viewport results at 320, 375, 390, 412, 768, 1024 and 1440.
4. Record body overflow, clipping, nav behavior, table strategy, focus/keyboard and state handling.
5. Do not convert an observed failure into PASS by changing product code unless phase scope is explicitly amended.
