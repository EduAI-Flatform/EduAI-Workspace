# EduAI Major Phases

This directory contains CongDongNgonNgu-style phase dossiers for new EduAI programs. It does not replace `.ai-dos/records/` for the active Phase 3 commerce/payment lane.

Each executable phase should have, at minimum:

- `README.md` — objective, scope, entry/exit gates and authorization state
- `TASKS.md` — dependency-ordered work
- `ACCEPTANCE.md` — completion gates
- `TEST-PLAN.md` — verification plan
- `UI-STITCH.md` — Stitch requirements or explicit not-applicable reason

Current program: [`ADMIN-UI-ROADMAP.md`](ADMIN-UI-ROADMAP.md).

A dossier may be `READY` without being started. Major-phase implementation begins only after owner authorization is recorded in project/phase state.
