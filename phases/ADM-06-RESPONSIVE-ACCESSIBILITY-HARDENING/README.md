# ADM-06 — Mobile, Tablet & Accessibility Hardening

**Status:** PLANNED  
**Dependency:** ADM-05 DONE  
**Execution authorized:** NO

## Objective
Run cross-Admin responsive and accessibility hardening after all page families are implemented, eliminating inconsistencies that page-level tests can miss.

## Scope
All Admin routes at 320/375/390/412/768/1024/1440; body overflow, clipping, shell/drawer, dialogs, dropdowns, dense data, filters, pagination, touch targets, sticky/scroll behavior, keyboard/focus, semantics and reduced-motion behavior.

## Exit gate
Every Admin route meets the responsive/a11y contract or has an explicitly accepted exception with evidence.
