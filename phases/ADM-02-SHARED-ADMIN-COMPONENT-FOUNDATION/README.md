# ADM-02 — Shared Admin Component Foundation

**Status:** PLANNED  
**Dependency:** ADM-01 DONE  
**Execution authorized:** NO

## Objective
Implement the approved Admin shell/design language as maintainable shared project-native primitives before redesigning all page families.

## Scope
Admin shell/sidebar/mobile navigation, page headers, panels/metrics, filters/search, dense tables and mobile record views, status badges, action menus, dialogs/forms/detail drawers and common loading/empty/error states as justified by real usage.

## Out of scope
Mass rewriting every feature page; backend/payment semantic changes.

## Exit gate
Shared foundation is implemented, tested and architecture-conformant; at least representative surfaces prove desktop/mobile integration without regression.
