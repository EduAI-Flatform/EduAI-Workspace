# EduAI Platform Charter

## Project Name

EduAI Platform

## Project Type

AI-Powered Digital Education Ecosystem

## Architecture Decision

EduAI MVP is **Single Tenant**.

This means the platform is operated as one unified EduAI system.

There is no multi-tenant SaaS architecture in Phase 1.

The system does not support separate isolated organizations, schools, or training centers with their own tenant-level data boundary in MVP.

## Mission

Build an AI-first digital education platform that combines:

- Digital Identity
- Digital Learning
- Live Classroom
- Digital Library
- Learning Community
- AI Assistant
- Digital Certificates

into one unified web platform.

## MVP Duration

50 days.

## MVP Includes

- Backend
- Frontend web app
- Responsive desktop browser
- Responsive mobile browser
- Production deployment

## MVP Excludes

- Mobile app
- Multi-tenant SaaS
- University ERP
- School ERP
- Admission management
- Tuition management
- Marketplace
- Payment
- Affiliate
- Career Hub
- Mentor System

## Target Users

- Students
- Instructors
- Platform Admins
- Independent learners
- Online educators

## Product Philosophy

EduAI must be:

- AI-first
- Backend-first
- Mobile browser responsive
- Modular monolith
- API-driven
- Secure by default
- Simple enough to finish MVP in 50 days

## Success Criteria

The MVP is successful when:

- Users can register and login.
- Instructors can create and publish courses.
- Students can enroll and learn.
- Students can join live classes.
- Students can use AI Tutor.
- Instructors can generate AI quizzes.
- Students can receive QR-verifiable certificates.
- The system is deployed and usable on desktop and mobile browsers.
