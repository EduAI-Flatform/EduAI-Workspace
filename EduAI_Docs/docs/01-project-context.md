# Project Context

## Problem

Current learning tools are fragmented.

Students and instructors often use many separate tools:

- Zoom or Google Meet for live classes
- Google Drive for documents
- Facebook groups or Discord for community
- Moodle or Google Classroom for course management
- ChatGPT for AI assistance
- Canva or manual tools for certificates

This causes:

- Scattered learning data
- Poor progress tracking
- Weak learning personalization
- No unified learning identity
- No integrated AI learning context

## Solution

EduAI unifies core learning activities into one platform:

- Digital profile
- Course learning
- Live classroom
- Digital library
- Community discussion
- AI Tutor
- Certificate verification

## Single Tenant Scope

EduAI MVP is one centralized platform.

There is one global platform admin group.

Instructors and students operate inside the same shared EduAI environment.

There are no separate tenant organizations in MVP.

## Core User Journey

1. User registers.
2. User completes profile.
3. Instructor creates course.
4. Student enrolls in course.
5. Student watches lessons.
6. Student completes quiz or assignment.
7. Student joins live classroom.
8. Student asks AI Tutor for help.
9. Student completes course.
10. System issues certificate with QR verification.

## MVP Business Model

Phase 1 revenue can come from:

- SaaS-like subscription managed manually outside the system
- AI premium subscription managed manually
- Certificate verification value
- B2B training deployment manually handled

In-app payment is not included in MVP.

## Long-Term Expansion

Phase 2 may add:

- Career Hub
- Mentor System
- AI Learning Path

Phase 3 may add:

- Marketplace
- Course Selling
- Payment
- Affiliate
