# Sprint 26 - Advanced Analytics

## Goal

Provide trusted revenue, membership, product, funnel, voucher, and entitlement
usage metrics derived from authoritative commerce records.

## Tasks

1. `SPR26-001` - Metrics contracts and privacy boundaries.
2. `SPR26-002` - Revenue, order, payment, and refund reporting.
3. `SPR26-003` - Membership MRR, renewal, expiry, and churn reporting.
4. `SPR26-004` - Product, voucher, checkout, and entitlement usage reporting.
5. `SPR26-005` - Export, accuracy, authorization, performance, and UAT.
