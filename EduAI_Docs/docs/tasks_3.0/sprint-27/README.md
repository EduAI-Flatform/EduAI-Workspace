# Sprint 27 - Affiliate

## Goal

Attribute eligible commerce, calculate auditable commissions, and support
administrator-reviewed withdrawal requests without automatic payouts.

## Tasks

1. `SPR27-001` - Affiliate policy and immutable financial model.
2. `SPR27-002` - Referral attribution.
3. `SPR27-003` - Commission lifecycle and ledger.
4. `SPR27-004` - Administrator affiliate operations.
5. `SPR27-005` - Affiliate dashboard and withdrawal requests.
6. `SPR27-006` - Abuse controls, financial invariants, and UAT.
