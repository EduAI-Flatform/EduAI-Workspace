# Tasks Compatibility & Phase Dossiers

This directory remains a compatibility location for the existing AI-DOS task model. Canonical AI-DOS task state lives in `.ai-dos/records/tasks.json` and `.ai-dos/records/project.state.json`.

New major-phase orchestration uses `phases/` rather than adding ad-hoc task files here.

For Admin UI work:

1. Read `../state/PROJECT-STATE.md` and `../state/DEPENDENCY-GRAPH.md`.
2. Read `../phases/ADMIN-UI-ROADMAP.md`.
3. Read the current ADM phase dossier (`README`, `TASKS`, `ACCEPTANCE`, `TEST-PLAN`, `UI-STITCH`).
4. Use `../templates/PHASE-TASK-TEMPLATE.md` when adding a substantial new subtask.

Do not edit this compatibility layer to fake completion of an AI-DOS task or financial release gate.
